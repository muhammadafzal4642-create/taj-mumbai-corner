# Taj Mumbai Corner – Luxury Dining & Authentic Flavours 🍽️

Taj Mumbai Corner is an elegant, modern restaurant web application built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**. It showcases authentic Mumbai cuisine, signature biryanis, clay-oven tandoori specialties, live table reservations, interactive menu browsing, and direct WhatsApp ordering.

---

## ✨ Features

- 🌟 **Luxury Design & Animations**: Sleek dark gold aesthetic powered by modern CSS & Framer Motion.
- 📜 **Interactive Menu**: Full culinary showcase with categories (Starters, Main Course, Tandoor, Desserts, Beverages).
- 📅 **Table Reservations Modal**: Instant table booking workflow with date/time pickers and guest counts.
- 💬 **WhatsApp Drawer & Direct Ordering**: Real-time order customization and direct WhatsApp communication.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- ⚡ **Lightning-Fast**: Built on Vite 8 & React 19 for optimal performance.

---

## 🛠️ Tech Stack

- **Framework**: React 19 & TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Motion (Framer Motion)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/muhammadafzal4642-create/taj-mumbai-corner.git
   cd taj-mumbai-corner
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🌐 Deploying to Vercel

This project is pre-configured for seamless deployment to **Vercel** with SPA route rewriting included in [`vercel.json`](vercel.json).

### Option 1: Deploy via Vercel Dashboard (Recommended)

1. Go to [Vercel Dashboard](https://vercel.com/new).
2. Click **Add New** > **Project**.
3. Import your GitHub repository: `muhammadafzal4642-create/taj-mumbai-corner`.
4. Vercel automatically detects **Vite**:
   - **Framework Preset**: `Vite`
   - **Root Directory**: `./`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**!

### Option 2: Deploy using Vercel CLI

```bash
npm i -g vercel
vercel
```

Follow the prompts to link and deploy your project instantly.
